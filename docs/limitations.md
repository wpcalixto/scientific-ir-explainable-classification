# Limitations

- Cross-validation predictions and fold assignments were not archived; they are regenerated deterministically by the code (seed 42).
- The original assessment sheets (spreadsheets and transcriptions with assessor identities) are not distributed; the pseudonymized grades
  (letters K–W, X–Z and replication teams) are archived and all human metrics can be recomputed from them. The blinding maps
  (`*_NAO_ENVIAR.csv`; document codes, ranks, strata and bibliographic metadata only) are distributed now that the assessments are closed.
- Collection and LLM stages depend on external services, API keys and paid quotas.
- Identity of human assessors is not disclosed; the human authorship of the returned sheets could not be verified independently.
